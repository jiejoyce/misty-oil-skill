# 雾色流彩 · 照片油画 Skill

将自己的旅行照片转换为留白充足、橘色秋意与浅雾蓝水面交织的极简抽象油画，默认 9:16 竖屏。

![效果参考图](assets/style-reference.png)

## 给豆包或其他 AI 的下载指令

复制下面整段到支持访问 GitHub、读取文件及图片编辑的 AI：

> 请从 https://github.com/jiejoyce/misty-oil-skill 下载「雾色流彩」技能。读取根目录的 SKILL.md 和 assets/style-reference.png。若支持自定义 Skill，请按当前环境的真实要求安装并验证；若不支持安装，请把技能规则加载到本次对话。请如实说明是安装还是读取规则，不要虚构安装成功。完成后等待我上传原照片，先制作一张 9:16 竖屏样片，确认后再处理其余图片。不能下载、读取图片或编辑图片时，请说明具体限制。

## 手动使用

1. 点击 GitHub 的 Code → Download ZIP 并解压。
2. 向图片编辑对话上传自己的原照片，再上传 assets/style-reference.png。
3. 让 AI 读取 SKILL.md；不支持文件读取时，复制其中的规则正文。
4. 说明人物、宠物是否保留，先生成一张样片。

## 风格与主体规则

- 浅雾蓝与柔和青蓝、奶油白与蜜桃沙色、温暖橘色秋叶。
- 少量主要景物、细暗树枝、局部刮刀厚涂、岸线与倒影融化成细长垂流笔触。
- 默认保留原片主角及宠物，移除无关游客和杂物。
- “去掉人物”包含骆驼骑手与牵引者，骆驼保留；“去掉人和狗”同时移除两者。
- 不凭空添加参考图中的景物，不拼图，不加文字、水印或边框。

## 文件

- SKILL.md：技能规则与图片编辑提示词。
- assets/style-reference.png：无人物的目标风格参考图。
- agents/openai.yaml：兼容工具可使用的展示元数据。

## 兼容说明

这是一套指令和参考图，不是图片模型或可在所有平台一键安装的插件。需要所用平台支持对应的文件访问和图片编辑能力。不同模型、原照片和生成批次会产生差异，不保证完全相同。
